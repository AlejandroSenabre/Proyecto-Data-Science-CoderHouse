# Predicción de Riesgo Crediticio: Análisis y Modelado de Préstamos Bancarios 🏦📊

Este proyecto, desarrollado originalmente para el curso de **Data Science en CoderHouse**, tiene como objetivo predecir la probabilidad de incumplimiento (*default*) de los clientes de una entidad financiera. El análisis combina técnicas de estadística avanzada y algoritmos de Machine Learning para optimizar la toma de decisiones crediticias.

## 📋 Resumen del Proyecto
La gestión del riesgo es el corazón de la industria financiera y actuarial. Este repositorio aborda el problema de clasificación para determinar si un préstamo será pagado o si entrará en mora, basándose en el historial demográfico y financiero de los aplicantes.

## 🛠️ Stack Tecnológico
*   **Lenguaje:** Python 🐍
*   **Librerías Principales:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn.
*   **Entorno:** Jupyter Notebook.

## 📂 Estructura del Repositorio
*   **`Prediccion de riesgo crediticio Final.pdf`**: Informe ejecutivo detallando la metodología, métricas de evaluación y conclusiones de negocio.
*   **`Proyecto_Prestamos_Bancarios.ipynb`**: Notebook con el flujo completo de trabajo: limpieza de datos, análisis exploratorio (EDA), ingeniería de variables y entrenamiento de modelos.
*   **`data/`**: Carpeta que contiene el dataset utilizado para el entrenamiento y testeo del modelo.

## 📊 Fases del Análisis
1.  **Exploración de Datos (EDA):** Identificación de patrones de comportamiento y correlaciones entre variables financieras.
2.  **Preprocesamiento:** Tratamiento de datos faltantes, codificación de variables categóricas y normalización de escalas.
3.  **Modelado:** Implementación y comparación de distintos modelos de clasificación (ej. Regresión Logística, Random Forest, Gradient Boosting).
4.  **Evaluación:** Uso de métricas críticas para el negocio como **AUC-ROC**, **Matriz de Confusión**, **Precisión** y **Recall** para minimizar el riesgo de falsos negativos.

## 🚀 Impacto del Proyecto
El modelo permite a las instituciones financieras:
*   Reducir la tasa de morosidad mediante una pre-calificación más precisa.
*   Automatizar procesos de aprobación de créditos.
*   Identificar variables clave que influyen en el comportamiento crediticio.
